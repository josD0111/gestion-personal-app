# Gestión Personal App

Aplicación web para gestión personal, desarrollada como proyecto de aprendizaje del proceso completo de desarrollo de software: levantamiento de requisitos, diseño, implementación, pruebas y despliegue, siguiendo una metodología ágil simplificada.

## Estado actual del proyecto

🔵 **Diseño finalizado, lista para implementación** — Iteración 1 en curso.

Módulo activo: **Tareas y Recordatorios**.

## Visión del producto

La aplicación contempla, a futuro, distintos módulos de gestión personal:

- ✅ Tareas y recordatorios *(en desarrollo — Iteración 1)*
- ⏳ Hábitos
- ⏳ Gestión financiera
- ⏳ Calendario
- ⏳ Estudio (pomodoro, apuntes)
- ⏳ Lista de compras/pagos

No todos los módulos se desarrollan a la vez. Ver [`docs/01-analisis/decisiones-alcance.md`](docs/01-analisis/decisiones-alcance.md) para el detalle de priorización.

## Plataforma

Aplicación web (responsive), pensada para uso desde notebook y celular vía navegador. Evolución futura contemplada hacia PWA y, eventualmente, apps nativas.

## Metodología de trabajo

Ágil simplificada (inspirada en Scrum/Kanban), con:
- Product Backlog priorizado
- Historias de usuario con criterios de aceptación
- Iteraciones cortas con objetivo concreto, revisión y retrospectiva
